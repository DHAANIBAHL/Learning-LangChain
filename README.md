# Learning-LangChain

A learning repository for understanding the fundamentals of **LangChain** and building the foundation needed to work with **LangGraph** and graph-based AI workflows.

This repository contains notes, experiments, examples, and small implementations created while learning how LLM applications are built using LangChain.

---

## Purpose

The main goal of this repository is not to master every feature of LangChain, but to understand the core concepts required to move toward:

- LangGraph
- Stateful LLM workflows
- AI agents
- Tool-based workflows
- Graph-based applications
- Relationship and schema modeling
- Working with structured and synthetic data

The learning process focuses on understanding **how LLMs interact with applications and how different components can be connected into workflows**.
